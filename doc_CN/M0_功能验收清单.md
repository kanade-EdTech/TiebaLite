## 3. 缺陷分类规则

- **原有缺陷**：在基线提交与 API 29 环境可以稳定复现。
- **迁移回归**：基线版本正常，但后续里程碑版本异常。
- **环境问题**：由测试设备、网络、账号或服务端状态导致，必须附证据。
- **待确认**：证据不足，不能直接归类为迁移回归。
